# Custom Extensions

**Note:** The modules documented here are **custom extensions** built by community members, NOT part of the official amplifier-foundation ecosystem.

## Memory Modules (Custom)

The following memory modules are custom implementations that extend Amplifier with persistent memory capabilities:

### tool-memory
- **Repository:** https://github.com/michaeljabbour/amplifier-module-tool-memory
- **Type:** Custom tool module (not official foundation)
- **Purpose:** SQLite-based persistent memory with full-text search
- **See:** [MEMORY.md](https://github.com/michaeljabbour/amplifier-cli-skill/blob/6904eca0980767cff8d3c70033839f6c1535dffc/skills/amplifier-cli-skill/references/MEMORY.md) for implementation details

### hooks-memory-capture
- **Repository:** https://github.com/michaeljabbour/amplifier-module-hooks-memory-capture
- **Type:** Custom hook module (not official foundation)
- **Purpose:** Automatic capture of learnings from tool outputs
- **See:** [MEMORY.md](https://github.com/michaeljabbour/amplifier-cli-skill/blob/6904eca0980767cff8d3c70033839f6c1535dffc/skills/amplifier-cli-skill/references/MEMORY.md) for implementation details

### context-memory
- **Repository:** https://github.com/michaeljabbour/amplifier-module-context-memory
- **Type:** Custom context manager (not official foundation)
- **Purpose:** Progressive disclosure of memory context
- **See:** [MEMORY.md](https://github.com/michaeljabbour/amplifier-cli-skill/blob/6904eca0980767cff8d3c70033839f6c1535dffc/skills/amplifier-cli-skill/references/MEMORY.md) for implementation details
